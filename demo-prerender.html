Student Question:

How do I solve \(e^z = 4 - 2i\)?

AI Tutor Response:

Underlying Theory

From Section 5: Euler’s Formula and Complex Exponential Equations, we do not use complex logarithms to solve equations of the form \(e^z = w\). Instead, we use the Identity Theorem:

Two equal complex numbers must have the exact same modulus and the same argument (up to an integer multiple of \(2\pi\)).

Steps to solve \(e^z = w\): 1. Set \(z = a + bi\), which gives \(e^z = e^{a+bi} = e^a e^{ib} = w\). 2. Same Modulus: \[|e^a e^{ib}| = |w| \implies e^a = |w| \implies a = \ln(|w|)\] (where \(\ln\) is the standard real logarithm). 3. Same Argument: \[\text{arg}(e^a e^{ib}) = \text{arg}(w) \implies b = \text{Arg}(w) + 2p\pi, \quad p \in \mathbb{Z}\] 4. Combine the real and imaginary parts into the complete solution: \[z = a + bi\]

Step-by-Step Solution

We want to solve: \[e^z = 4 - 2i\]

Let \(z = a + bi\), where \(a, b \in \mathbb{R}\). This gives: \[e^a e^{ib} = 4 - 2i\]

1. Find the real part \(a\) (Same Modulus)

Calculate the modulus of the right-hand side using \(|w| = \sqrt{\text{Re}(w)^2 + \text{Im}(w)^2}\): \[|4 - 2i| = \sqrt{4^2 + (-2)^2} = \sqrt{16 + 4} = \sqrt{20} = 2\sqrt{5}\]

Equating the moduli: \[e^a = |4 - 2i| = \sqrt{20}\] \[a = \ln(\sqrt{20})\]

2. Find the imaginary part \(b\) (Same Argument)

From the trigonometric relations for \(w = 4 - 2i\): - \(\cos(\theta) = \frac{\text{Re}(w)}{|w|} = \frac{4}{\sqrt{20}} = \frac{2}{\sqrt{5}} > 0\) - \(\sin(\theta) = \frac{\text{Im}(w)}{|w|} = \frac{-2}{\sqrt{20}} = -\frac{1}{\sqrt{5}} < 0\)

Since \(\cos(\theta) > 0\) and \(\sin(\theta) < 0\), the principal argument \(\text{Arg}(4 - 2i)\) lies in the 4th quadrant (\(]-\pi; \pi]\)).

Therefore, all arguments are: \[b = \text{arg}(4 - 2i) = \text{Arg}(4 - 2i) + 2p\pi, \quad p \in \mathbb{Z}\] (where \(\text{Arg}(4 - 2i) = -\arccos\left(\frac{2}{\sqrt{5}}\right)\) or \(-\arcsin\left(\frac{1}{\sqrt{5}}\right)\)).

3. Combine into \(z\)

Putting the real and imaginary parts together: \[z = \ln(\sqrt{20}) + i\left(\text{Arg}(4 - 2i) + 2p\pi\right), \quad p \in \mathbb{Z}\]
